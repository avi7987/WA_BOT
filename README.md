# 🤖 המנהל האישי — בוט משימות בוואטסאפ

בוט שמתחבר לוואטסאפ **שלך** (המספר האישי, בלי מספר נוסף), מקשיב אך ורק לצ'אט
**"הודעה לעצמי"**, ומנהל בשבילך את כל המשימות. כותבים או מקליטים לו בשפה חופשית,
והוא זוכר, מסדר, ומקפיץ כל בוקר את הרשימה.

```
☀️ בוקר טוב, אבישי
יום שישי · 7 באוגוסט
2 באיחור · 3 להיום · 6 בהמשך השבוע

🔴 באיחור (2)
1. באיחור של 3 ימים · לשלם ארנונה
2. אתמול · להתקשר למוסך

🟠 להיום (3)
3. לסיים את המצגת
4. 14:00 · פגישה עם רו״ח

👥 משותף עם איה (2)
6. מחרתיים · להזמין מסעדה ליום שישי

⚠️ שווה בדיקה
• נראה שיש כפילות: "לשלם ארנונה" (1) ו-"לשלם את הארנונה" (11).
• "פגישה עם רו״ח" ו-"לקנות מתנה לאמא" קבועות כמעט לאותה שעה.

ענה במספר כדי לסמן שבוצע (למשל: 1,3) · "דחה 2 מחר" · "עזרה"
```

## איך זה בנוי

```
וואטסאפ (הצ'אט עם עצמך)
        │  whatsapp-web.js — מכשיר מקושר, כמו וואטסאפ ווב
        ▼
   tasks-bot  ──►  Gemini / Groq   (הבנת עברית + תמלול, שכבה חינמית)
        │
        ▼
   Supabase (Postgres)  — המשימות. RLS נעול: רק הבוט ניגש.
```

| קובץ | תפקיד |
|---|---|
| `src/index.js` | מרים סשן וואטסאפ לכל אדם, מחבר הכל |

| `src/brain.js` | הודעה נכנסת → פעולה → תשובה |
| `src/parse.js` | תאריכים ופקודות בעברית, בלי AI (המסלול המהיר) |
| `src/llm.js` | Gemini/Groq — הבנה חופשית ותמלול |
| `src/tasks.js` | הוספה/סימון/דחייה + זיהוי כפילויות |

## התקנה

### 1. בסיס הנתונים (5 דקות)

1. היכנס ל-[supabase.com](https://supabase.com) → **New project** (תוכנית Free).
2. **SQL Editor** → New query → הדבק את כל `db/schema.sql` → **Run**.
3. **Project Settings → API** → העתק את `Project URL` ואת `service_role` key.

> ה-`service_role` key הוא מפתח-על. הוא נכנס רק לקובץ `.env` שנשאר אצלך — לעולם לא לגיטהאב.

### 2. מפתח AI חינמי (2 דקות)

היכנס ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key**.
חינם, בלי כרטיס אשראי. אותו מפתח עושה גם הבנת עברית וגם תמלול הקלטות.

*(אפשר גם Groq מ-[console.groq.com/keys](https://console.groq.com/keys) — אז `LLM_PROVIDER=groq`.)*

### 3. הגדרות

```bash
cp .env.example .env
```

ומלא: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `GEMINI_API_KEY`, `OWNER_NAME`, `PARTNER_NAME`.

### 4. הרצה ראשונה

```bash
npm install
npm start
```

בטרמינל יופיע קוד QR. בטלפון: **וואטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר** → סרוק.
אם הפעלת `ENABLE_PARTNER=true`, יופיע קוד שני — אותו סורקים מהטלפון של בן/בת הזוג.

מיד אחרי החיבור תקבל הודעת פתיחה בצ'אט "הודעה לעצמי". משם פשוט מתחילים לכתוב.

## הרצה 24/7 בענן (חינם)

הבוט חייב להיות דלוק כדי לשלוח את סיכום הבוקר. השרת החינמי־לתמיד המומלץ הוא
**Oracle Cloud Always Free** (4 ליבות ARM / 24GB זיכרון — יותר ממספיק לשני סשנים).

1. הרשמה ב-[cloud.oracle.com](https://cloud.oracle.com) — כרטיס אשראי לאימות בלבד, לא מחויב.
2. **Create VM Instance** → Image: *Ubuntu 22.04* → Shape: **VM.Standard.A1.Flex** (Always Free), 2 OCPU / 12GB.
3. שמור את קובץ ה-SSH key, והתחבר: `ssh ubuntu@<IP>`
4. על השרת:

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
sudo usermod -aG docker $USER && newgrp docker
git clone https://github.com/avi7987/WA_BOT.git && cd WA_BOT
nano .env          # מדביקים את אותם ערכים מהמחשב
docker compose up -d --build
docker compose logs -f      # כאן מופיע ה-QR לסריקה
```

5. סרוק את שני קודי ה-QR (שלך, ואז של בן/בת הזוג). זהו — הבוט חי.

הסשן נשמר ב-Volume, כך שגם אחרי `docker compose restart` אין צורך לסרוק שוב.

> **חלופות:** Fly.io, Koyeb, או פשוט להשאיר `npm start` רץ על מחשב שדלוק תמיד.
> Render בתוכנית החינמית מרדים שירותים — לא מתאים כאן.

## פרטיות ואבטחה

* הבוט קורא **אך ורק** את הצ'אט של כל אחד עם עצמו. כל שיחה אחרת — כולל השיחה הזוגית שלכם —
  לא נקראת, לא נשמרת ולא מגיעה לשום מקום.
* טבלאות ה-Supabase נעולות ב-RLS **בלי אף מדיניות גישה** — רק ה-worker עם `service_role`
  יכול לקרוא אותן. אין דרך להגיע אליהן מהדפדפן.
* קוד ה-QR נמחק מהדיסק ברגע שהחיבור מצליח.
* טקסט המשימות (ותמלול ההקלטות) נשלח לספק ה-AI שבחרת לצורך הפענוח. אם זה מפריע —
  `LLM_PROVIDER=none` משאיר הכל מקומי, במחיר הבנה פחות גמישה ובלי תמלול.

**הערה חשובה:** החיבור נעשה דרך `whatsapp-web.js`, שהיא ספרייה לא רשמית. זה נוגד את תנאי
השימוש של מטא ויש סיכון (קטן, אך אמיתי) לחסימת המספר. זו הדרך היחידה לעבוד עם מספר אישי קיים.
